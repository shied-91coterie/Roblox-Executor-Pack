## FAQ

### What is XCutors?

XCutors is a curated package of multiple popular Roblox executors and a universal loader, designed for running custom Lua scripts on the Windows platform.

### Are these executors safe to use?

XCutors itself is a launcher and collection. The safety of individual scripts or executor versions depends on their source and your own usage. Always scan files with a reputable anticomponent.

### Which Windows versions are supported?

XCutors and its included components are primarily developed for and tested on Windows 10 and Windows 11.

### How do I update the executors?

Check the GitHub repository's Releases page periodically. Download the new package and replace the files in your existing folder, or extract to a new one.

### Can I use this on a Mac or Linux?

No. The executors and loader included in XCutors are Windows-only applications.

### Why isn't the executor working?

This can be due to several factors: Roblox updates, anticomponent interference, or specific script issues. Check the FAQ in the executor's Discord (if available) or try another executor from the pack.

### Is there a Discord or support channel?

Please refer to the main repository's 'Community' section or README for any official links to support or discussion channels.

### Can I add my own executor to the loader?

The current version of xcutorsLoader is designed for the included executors. Adding new ones would require modifying the source code, which is not officially supported.
